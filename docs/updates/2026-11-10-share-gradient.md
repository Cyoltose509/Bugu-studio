# 图片卡头渐变映射

图片填充的分享卡头可调节整体不透明度，以及遮罩从透明网格到遮罩色的渐变映射。两个滑杆左右对齐；三角柄仅标注 `x0`、`x1`，拖动或用键盘方向键可改变位置。旧的操作提示已移除。

功能代码见提交 `111d630`。以下截图来自开发预览，使用公开活动示例数据。
