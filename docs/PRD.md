# 产品需求文档 (PRD)
## 大学游戏开发社团官方网站

**版本**: 1.0.0  
**日期**: 2026-06-07  
**作者**: Tech Lead  
**状态**: 待评审

---

## 1. 产品定位

### 1.1 一句话定位

> 大学游戏开发社团的「作品档案馆 + 对外门户」，承载社团历史、展示成员作品，服务于迎新宣传和文化传承。

### 1.2 核心价值主张

| 维度 | 描述 |
|------|------|
| 历史保存 | 将分散在各平台的作品归档至统一数据库 |
| 对外展示 | 作为社团对外宣传的权威入口 |
| 传承资产 | 每届社长可平滑交接，持续运营5年以上 |
| 招募工具 | 迎新季展示社团实力，降低招募成本 |

### 1.3 不是什么

- **不是游戏下载站**：不托管游戏本体，只保存外链
- **不是社交平台**：不含 Feed 流、点赞、评论等社交功能（V3 前）
- **不是文件托管**：大文件通过外链指向 Steam / GitHub / 网盘

---

## 2. 目标用户

| 用户类型 | 场景 | 核心需求 |
|----------|------|----------|
| 访客/招募对象 | 迎新季浏览 | 快速了解社团实力和历史作品 |
| 在读社员 | 日常使用 | 提交作品、完善资料、内部浏览 |
| 往届毕业生 | 偶尔回访 | 查看自己参与的历史项目 |
| 社长/管理员 | 日常运营 | 审核内容、管理成员、更新公告 |
| 新入社成员 | 了解社团 | 了解社团文化和前辈成果 |

## 3. 功能模块详述

### 3.1 首页 (Home)

**功能列表**:
- 社团 Hero Banner（Logo + Slogan + CTA 按钮）
- 社团统计数据展示：成立年份、历届成员数、累计作品数、Steam 作品数
- 精选作品轮播（最新 / 编辑推荐 / Steam 已发布）
- 最新公告列表（最新 3 条）
- 历年成果时间线预览

**交互规则**:
- 统计数字使用动态计数器效果
- 精选作品卡片展示封面、标题、年份、主要标签
- 公告支持置顶标记

### 3.2 作品库 (Works)

**功能列表**:
- 作品卡片列表（分页，每页 12 条）
- 全文搜索（标题、简介、标签）
- 多维筛选：
  - 类型：Steam 正式发布 / 独立游戏 / Game Jam / Demo / 毕业设计 / 原型
  - 标签：多标签 AND/OR 筛选
  - 年份：单年 / 年份区间
- 作品详情页：
  - 封面图 + 截图画廊
  - 基础信息（标题、简介、类型、年份）
  - 开发团队成员（可跳转成员页）
  - 外部链接（Steam / GitHub / Itch.io / 网盘）
  - 视频演示嵌入（YouTube / Bilibili iframe）
  - 开发日志（Markdown 渲染）

**业务规则**:
- 截图最多 10 张，单张最大 5MB
- 封面图必填，截图可选
- 所有外链在提交时格式校验，不存储文件内容
- 作品状态：`draft` → `pending_review` → `published` / `rejected`

### 3.3 成员页 (Members)

**功能列表**:
- 成员列表（按入社年份分组）
- 成员详情页：
  - 头像、昵称、年级、入社/毕业年份、个人简介
  - 参与的所有作品列表（可按角色筛选：主策/主程/主美/音效等）
- 在读成员 / 毕业成员分类展示

**隐私规则**:
- 真实姓名不公开，仅展示昵称
- 联系方式不对游客展示
- 毕业成员默认标注"已毕业"

### 3.4 历史页 (History)

**功能列表**:
- 按年份（学年）展示社团历史
- 每年包含：当年成员列表、当年项目列表、活动记录
- 时间轴可视化（大事件节点）
- 支持 Admin 添加年度备注/大事件

### 3.5 投稿系统 (Submit)

**功能列表**（Member 专属）:
- 分步骤表单（基础信息 → 多媒体 → 外链 → 确认提交）
- 草稿自动保存（localStorage + 服务端）
- 提交后进入审核队列
- 审核状态通知（站内通知，后续可扩展邮件）

**审核流程**:
```
提交 → pending_review → Reviewer 审核
  → approved: 自动发布，通知提交者
  → rejected: 保存审核意见，通知提交者，允许修改后重提
```

### 3.6 管理后台 (Admin)

**功能列表**:
- 用户管理：列表、角色变更、启用/禁用
- Member 身份审批：待审批列表、通过/拒绝
- 作品管理：全量列表、强制编辑/删除、批量操作
- 审核队列：待审核作品列表
- 公告管理：CRUD、置顶设置
- 网站设置：社团介绍文本、联系信息、精选作品配置
- 操作日志：全量审计日志查看

## 4. 非功能需求

| 指标 | 目标值 |
|------|--------|
| 页面加载时间 (LCP) | < 2.5s（4G 网络） |
| 可用性 | 99.5% 月均（允许计划内维护） |
| 并发用户数 | 支持 200 并发（迎新高峰） |
| 数据备份 | 每日全量备份，保留 30 天 |
| 安全漏洞响应 | P0 漏洞 24h 内修复 |
| 浏览器兼容 | Chrome 90+, Firefox 88+, Safari 14+, Edge 90+ |
| 响应式 | 移动端 375px 以上正常使用 |

## 5. MVP 版本规划

### V1 — 迎新前上线（目标：6 周）

**核心目标**：让访客能看到社团作品和成员，管理员能通过后台录入数据。

**功能范围**:
- [x] 首页（静态内容 + 统计数据）
- [x] 作品库（列表 + 详情 + 搜索 + 筛选）
- [x] 成员页（列表 + 详情）
- [x] 历史页（静态展示）
- [x] 管理员后台（作品/成员/公告 CRUD）
- [x] 基础 RBAC（Guest / Admin）
- [x] 图片上传（封面 + 截图）
- [x] Docker 部署 + 每日备份

**V1 不做**:
- 用户注册
- 投稿系统
- 邮件通知

### V2 — 正式运营（目标：V1 + 8 周）

**功能范围**:
- [x] 用户注册 + 邮箱验证
- [x] Member 身份申请 + 管理员审批
- [x] Member 自助投稿表单
- [x] 审核工作流（Reviewer 角色）
- [x] 站内通知系统（基础）
- [x] 个人资料页完善

### V3 — 生态完善（目标：V2 + 12 周）

**功能范围**:
- [ ] 活动/赛事系统（Game Jam 专页）
- [ ] 作品收藏功能（User 角色）
- [ ] RSS 订阅
- [ ] 社团年报自动生成
- [ ] 开放 API（只读，用于展示嵌入）
