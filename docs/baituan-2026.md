# 2026 百团招新活动页

- 页面：`/activities/baituan-2026`（ID 路由同样可用）
- 时间：2026-10-11 09:00–17:00，北京时间
- 地点：桂园操场 · 拓新区 B20 摊位
- 试玩：东方魔女夜市、铅雨2、Step or Sink! 2、Saga Of Deadwood、萓active

## 管理与发布

在管理后台「活动管理」点击「10.11 百团招新专页」，会创建草稿并跳转编辑；已有活动会直接打开，不覆盖内容。

编辑页底部「海报与试玩目录」可以启用/停用专页、搜索并添加已发布作品、移除与排序作品、上传/移除/排序海报、编辑海报标题。第一张海报显示在首屏。保存海报与试玩目录后，点击预览检查效果。活动的标题、时间、地点、状态在上方表单独立保存。

确认后，将活动状态改为「已发布」。访客不能查看草稿；作品下架后自动从公开试玩目录消失。2024 新手村海报标为往期介绍，不作为本次日期依据。

试玩区使用手机一列、平板两列、桌面三列的 Grid。点击「全屏播放作品」按目录顺序播放每款作品的封面和截图，每张停留 6.5 秒。底部渐暗遮罩显示作品名、标签和简介；支持暂停、前后切换、方向键、缩略图选择和退出。浏览器不支持原生全屏时使用占满视口的弹层。启用系统「减少动态效果」时初始暂停。

## 数据与部署

沿用 `Activity` 和 `SiteSetting`，无数据库迁移或新增环境变量。配置键为 `activity-showcase:<activityId>`，作品引用保存 ID；页面每次读取最新的已发布作品。删除活动时在同一事务中清理配置。

三张提供的海报已优化为 WebP，随代码部署，不依赖额外上传。管理员新上传海报沿用现有 R2 上传接口。活动表单按北京时间解析，避免 Vercel 的 UTC 时区影响编辑后的时间。

运营初始化脚本：`node --import tsx scripts/prepare-baituan.ts` 仅检查；加 `--apply` 准备草稿。需要现有数据库连接环境变量。脚本不会发布活动，也不会覆盖已存在活动或目录。

当前仓库为 `Cyoltose509/Bugu-studio`，Vercel 由仓库持有人控制。合并代码后需确认其生产部署成功，再发布活动。准备好的草稿使用新代码随附图片，部署之前不要发布。

## 验证

`npx vitest run __tests__/unit/activity-showcase*.test.* __tests__/unit/activity-slideshow.test.tsx` 验证权限、目录引用、下架过滤、增删排序、保存失败、初始化幂等性、时区及轮播交互；`npm run build` 验证生产构建。浏览器检查桌面/手机布局、全屏轮播、完整海报灯箱及匿名草稿隔离。
