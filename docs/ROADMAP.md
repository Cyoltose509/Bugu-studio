# MVP 开发路线图

---

## 总体时间线

```
Week 1-2   环境搭建 + 数据库 + RBAC 骨架
Week 3-4   首页 + 作品库（前端展示）
Week 5     成员页 + 历史页
Week 6     管理后台 + 图片上传 + 内容录入
Week 7     安全加固 + 测试 + 部署
Week 8     数据录入 + 验收 → V1 发布

Week 9-12  用户注册 + 邮箱验证 + Member 审批
Week 13-16 投稿表单 + 审核工作流 → V2 发布

Week 17-28 活动系统 + Game Jam + 收藏 → V3 发布
```

## 关键决策记录

| 决策 | 原因 |
|------|------|
| V1 不做用户注册 | 优先完成数据录入，快速上线迎新 |
| 文件不托管在服务器 | 避免存储成本和带宽压力，外链策略可持续 |
| 采用数据库 Session（非 JWT）| 支持主动吊销 Session，更安全 |
| Docker Compose 而非 K8s | 大学社团运维能力有限，Compose 够用且易交接 |
| PostgreSQL 而非 MySQL | 更好的 JSON 支持、全文搜索、Prisma 生态 |
| 预签名 URL 上传 | 减轻服务器带宽压力，文件直达 R2 CDN |
